# Seed Scroll Desktop Releases

Installers for the Seed Scroll desktop app, and the feed it checks for updates.

Download the latest version from [seedscroll.app](https://seedscroll.app) or the [Releases page](https://github.com/repolife/seed-scroll-desktop-releases/releases/latest):

- **macOS:** `Seed Scroll-<version>-universal.dmg` (or the arm64/x64 build for your Mac)
- **Windows:** `SeedScrollSetup-x64.exe`
- **Linux:** `.AppImage` or `.deb`

Installed copies on macOS and Windows update themselves through
[update.electronjs.org](https://update.electronjs.org), which reads the releases published here.

This repository holds release files only. It has no source code, and it does not take issues or pull requests.
For help, see [seedscroll.app](https://seedscroll.app).
